<objective>
Split the currently fully-gated Parent Portal (D-08): make the read-only Quick Stats + practice heatmap always-visible (ungated child stat viewing) keyed on the active child, and move ONLY the action rows (subscription management, notification settings) behind the shared `ParentGateContext`. Migrate the notification-enable sub-flow off its own mount-local `ParentGateMath` onto the shared gate (D-06), add the Privacy Policy link to the parent-settings area (SIGNUP-05's second half, carried from Phase 3 D-12), and replace the page's local `gateOpen` useState with the shared gate.

Purpose: COPPA-01/D-08 — a child may view their own progress without the gate, but every parent action requires it. This decouples the portal's read-only stats from its gated actions and removes the portal's parent-id-as-studentId confusion by rescoping its stat queries to the active child. D-06 requires all three former ParentGateMath copies to share one window; this plan migrates the portal AND its embedded notification card so the notifications sub-flow no longer re-prompts.
Output: ParentPortalPage split + NotificationPermissionCard gate migration + Privacy link + updated tests.
</objective>
