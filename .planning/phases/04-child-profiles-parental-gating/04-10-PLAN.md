<threat_model>

## Trust Boundaries

| Boundary                             | Description                              |
| ------------------------------------ | ---------------------------------------- |
| child → /manage-children             | an unsupervised child could type the URL |
| delete action → irreversible cascade | permanent data loss                      |
| deactivate → stop-collection         | must actually prevent new data           |

## STRIDE Threat Register

| Threat ID  | Category                | Component               | Disposition     | Mitigation Plan                                                                                                                                                              |
| ---------- | ----------------------- | ----------------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-04-10-01 | Elevation of Privilege  | /manage-children access | mitigate        | Route wrapped in ParentGateProtectedRoute (mount re-check, Plan 05) — no URL/back-button bypass (COPPA-01/02)                                                                |
| T-04-10-02 | Tampering / Repudiation | delete                  | mitigate        | Gate + case-insensitive nickname confirmation + service-side verifyStudentDataAccess ownership + RLS before the irreversible students.delete(); parent not signed out (D-12) |
| T-04-10-03 | Information Disclosure  | export/review           | mitigate        | exportStudentData/downloadStudentDataJSON go through verifyStudentDataAccess (Plan 03) which enforces DB ownership; only parent-facing tables included                       |
| T-04-10-04 | Denial of Service       | deactivate              | accept/mitigate | setChildActive(false) hides the child from the switcher (Plan 09 filter) so no new data is collected while retaining existing data (COPPA-06); reversible by design          |

</threat_model>
