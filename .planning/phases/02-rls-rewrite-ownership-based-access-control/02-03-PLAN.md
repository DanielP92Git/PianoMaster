<objective>
Write the single atomic, additive migration (`20260801120000_rls_ownership_rewrite.sql`) that creates `owned_child_ids()`, adds `child_profiles`' two terminal policies, adds one `_parent_owner` sibling per in-scope (table, command) alongside — never replacing — the legacy policies, handles the 3 edge cases, re-points `award_xp`/`check_rate_limit`, and its committed paired down-migration.
