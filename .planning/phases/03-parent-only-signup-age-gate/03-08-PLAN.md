    Extend the `createProfile` mutationFn to branch on role, replacing the old `students` insert with a `parents` insert (D-06):
    ```javascript
    if (role === "teacher") {
      const { data, error } = await supabase.from("teachers").insert([{ id: user.id, first_name: firstName, last_name: lastName, email: user.email, is_active: true }]).select().single();
      if (error) throw error; return data;
    } else { // role === "parent"
      const { data, error } = await supabase.from("parents").insert([{ id: user.id, display_name: firstName || null, age_verified_at: new Date().toISOString() }]).select().single();
      if (error) throw error; return data;
    }
    ```
    (firstName/lastName may still be derived from `user.user_metadata.full_name` for the teachers row only — that is teacher profile data, not child data; the parents row takes only display_name.) Keep the existing `onSuccess` toast + `queryClient.invalidateQueries({ queryKey: ["user"] })` + `onRoleSelected()`.
